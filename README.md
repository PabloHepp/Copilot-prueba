# Sistema Educativo Infantil

Sistema educativo completo para niños de 5 a 8 años, diseñado para funcionar en modo kiosco en computadoras de escuelas primarias.

## 🎯 Características Principales

- **Modo Kiosco**: Previene acceso accidental a funciones del sistema
- **9 Aplicaciones Educativas**: Matemáticas, Lengua, Letras, Colores, Formas, Música, Rompecabezas, Actividades del Profesor y Juegos
- **Panel de Administración**: Para que los profesores creen actividades personalizadas
- **Diseño Responsive**: Optimizado para tablets y PCs de bajos recursos
- **Interfaz Amigable**: Diseñada específicamente para niños pequeños

## 📁 Estructura del Proyecto

```
├── index.html                    # Página de bienvenida
```

## 🚀 Cómo Usar

### Inicio Rápido
1. Abrir `index.html` en cualquier navegador
2. Hacer clic en "Iniciar Sistema Educativo"
3. ¡Listo! El sistema se ejecutará automáticamente

### Acceso Directo
- Abrir directamente `sistema-educativo.html` para acceso inmediato

## 🔐 Sistema de Seguridad

### Modo Kiosco
- **Activado automáticamente** al iniciar
- **Bloquea atajos de teclado** peligrosos (F11, F12, Ctrl+U, etc.)
- **Previene menú contextual** (clic derecho)
- **Código de salida de emergencia**: `SALIR123`

### Panel de Administración
- **Contraseña por defecto**: `admin123`
- **Configurable** desde el panel de administración
